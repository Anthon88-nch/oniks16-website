# ОНИКС — сайт строительных материалов (Набережные Челны)

Статический многостраничный сайт под задачи: **заявки** (обратный звонок, заявка на материалы через WhatsApp) и **SEO-продвижение** (96 страниц: категории и карточки товаров с уникальными title/description, schema.org-разметкой, sitemap).

## Структура

```
build.py            # генератор сайта (Python + Jinja2)
products_final.json # каталог: 80 товаров (названия, цены, описания)
templates/          # Jinja2-шаблоны страниц
site_src/           # статика: CSS, JS, favicon, фото товаров
site/               # ГОТОВЫЙ САЙТ (результат генерации) — публиковать эту папку
```

## Запуск

```bash
npm install       # один раз — ставит vite для локального превью
npm run dev       # превью на http://localhost:5173 (папка site/)
npm run generate  # пересобрать сайт из шаблонов и данных
```

## Что внутри

- **96 статических страниц**: главная, каталог, 11 категорий, 80 карточек товаров, «Оптовикам», «Доставка и оплата», «Контакты».
- **SEO**: семантическая разметка, хлебные крошки, JSON-LD (HardwareStore, Product, Offer, BreadcrumbList), canonical, Open Graph, `sitemap.xml`, `robots.txt`, ЧПУ-адреса.
- **Заявки без бэкенда**: формы «Заказать звонок» и «Оформить заявку» формируют сообщение и открывают WhatsApp менеджера; на карточках — кнопки «Позвонить» / «WhatsApp».
- **Производительность**: чистый HTML/CSS/JS без фреймворков, ленивая загрузка изображений, локальные фото товаров.
